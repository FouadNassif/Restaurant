### 📱 User-Friendly Interface
- Modern, responsive design that works seamlessly on both desktop and mobile devices
- Intuitive navigation with quick access to menu and special offers
- Beautiful animations and transitions for a smooth user experience
- Dark mode support for comfortable night-time ordering

### 🍽️ Menu Management
- Comprehensive menu with detailed item descriptions
- Multiple categories for easy browsing

  - Size options (S, M, L, XL, Family)

  - Special instructions

- Dietary preferences and allergen information

- Edit existing items

## 🛠️ Technical Stack

- **Frontend Framework**: Next.js 13+
- **UI Library**: Material-UI (MUI)
- **Language**: TypeScript
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Storage**: Cookies for persistence
- **Styling**: Emotion (MUI's styling solution)
- **Testing**: Jest & React Testing Library
- **Code Quality**: ESLint & Prettier
- **API Integration**: REST & GraphQL ready

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/restaurant-ordering-system.git
```

2. Install dependencies:
```bash
cd restaurant-ordering-system
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env.local
# Edit .env.local with your configuration
```

4. Run the development server:
```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
